# 추가 자료와 작성자 입력란

GitHub README는 프로젝트의 구성·동작·결과를 안내합니다. 개인 경험과 취업용 소개는 Notion에 별도로 정리할 수 있습니다. 이 문서는 README에 보완할 자료를 모으는 작성용 문서입니다. 공란은 확인 전까지 그대로 두며, 새 실험은 필수가 아닙니다.

## 1. 대표 사진과 Demo

**사용 위치:** 첫 화면. 만든 보드와 실제 구동을 빠르게 보여주는 자료입니다.

- 실물 사진 파일 또는 경로: ______
- 영상 파일 또는 링크: ______
- 촬영한 보드 버전·날짜: ______
- 영상의 CCR·전원·운전 조건: ______

보드와 모터가 함께 보이는 사진 한 장, 기동 후 노브로 속도를 변경하는 짧은 영상이면 시작할 수 있습니다. RPM을 측정하지 않았다면 속도 변화만 설명합니다.
