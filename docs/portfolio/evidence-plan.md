README 편집에는 [MBLDC](https://github.com/maakbaas/mbldc)의 짧은 소개·하드웨어/펌웨어 기능·사진 구성을 참고했습니다. 이는 문서 구성 참고이며, 본 ESC 회로·펌웨어의 설계 출처를 뜻하지 않습니다.

## 이번 초안의 근거

| 자료 | 접근 및 확인 범위 | 사용 목적 |
| --- | --- | --- |
| 로컬 FW 프로젝트 | Core의 소스·헤더, 프로젝트 파일, Git 상태 | 계층, 상태, 주변장치 역할 설명 |
| 로컬 KiCad 회로도 | 최상위 및 참조 하위 시트, 현재 회로도에서 내보낸 netlist | 블록 구성, 부품명·수량, 연결명 확인 |
| 로컬 KiCad PCB | 레이어 및 stackup 설정 | 4층·1.6mm 설계 확인 |
| 개발자 설명 | 2026년 1~10월 진행 과정, 작업 기여, 실물 패치, 무부하 구동·발열 관찰 | 개발 기록, 관찰 결과와 미검증 항목 표시 |

회로도 구성 파악을 위한 netlist export는 수행했지만, 이번 작업에서 ERC/DRC·회로 검증·재빌드·실물 시험을 새로 수행하지 않았습니다. 과거 검사 파일이 존재한다는 이유로 현재 설계의 통과 여부를 주장하지 않습니다.

펌웨어 기준 커밋은 `462d3e0`이고 로컬 미커밋 변경이 존재합니다. 문서는 커밋 스냅샷이 아닌 읽은 시점의 로컬 작업본을 설명합니다. 실제 보드에 다운로드된 바이너리와의 동일성은 아직 확인하지 않았습니다.

## 이번에 비워둔 증빙

- 로깅 프로그램의 화면과 상세 구현 소개
- 오실로스코프 사진과 파형 해석
- 대표 CSV 선정과 정량 분석
- 실제 모터 구동 영상
- 실물 PCB 사진 및 실제 실장 부품과 회로도의 대조

이 자료들을 모두 추가해야만 프로젝트를 마무리할 수 있는 것은 아닙니다. 이미 가진 자료 중 설명에 도움이 되는 것만 선정합니다. 새 실험은 이번 문서화의 필수 작업으로 두지 않습니다.

## 작성자 답변 반영 내용

- 초기 STM32F103RB 개발보드에서 현재 STM32F103C8 자체 보드로 이동했습니다.
- 첫 인버터 PCB는 모터 2채널이 아닌 앞·뒤 구리층을 사용하는 2층 PCB였습니다.
- 회로·PCB·BOM 작성, 외주 SMT와 직접 커넥터 납땜의 역할을 구분했습니다.
- USB 풀업 경로 패치와 Vcom 커패시터 제거 사례를 관찰·가설·조치로 나누었습니다.
- ARR=1800, CCR=1750 및 약 1분 운전, PSU 약 0.6A 표시는 개발자 관찰로 반영했습니다.
- AI 활용과 자료 조사 방식에 대한 회고를 [개발 기록](development-story.md)에 반영했습니다.

## 추후 보완할 내용

- 사용 도구의 실제 버전과 재현 가능한 빌드 절차
- 4층 PCB를 선택한 이유와 배치 의도 중 추가로 설명하고 싶은 부분
- 참고 책·블로그·영상·평가보드의 정확한 출처
- USB 패치 위치와 제거한 Vcom 커패시터의 부품 번호·용량
- 실물 수정과 현재 KiCad 회로도·PCB의 일치 여부
- 공개할 하드웨어 파일과 자료의 범위, 지원 직무의 구체적인 방향

기억이 불확실한 내용은 억지로 회고를 만들지 않고 생략하거나 미기록으로 남깁니다.

## GitHub에서의 구성

현재는 펌웨어 저장소의 루트 `README.md`와 `docs/portfolio/`를 진입점으로 사용합니다. GitHub에 반영하면 README가 저장소 첫 화면에서 표시되고, 상세 설명과 소스로 이동할 수 있습니다.

하드웨어는 현재 별도 로컬 프로젝트이므로 README에 미포함 상태를 밝혔습니다. 추후 공개하기로 정하면 이 저장소의 `hardware/`에 원본·필요한 라이브러리를 정리하거나, 별도 하드웨어 저장소로 연결할 수 있습니다. 이 단계에서는 하드웨어 파일을 복사하지 않았습니다.

| 단계 | 결과 |
| --- | --- |
| 로컬 Markdown 작성 | 현재 단계. 사용자 검토 가능 |
| Git commit | 선택한 파일을 버전 이력으로 기록 |
| Git push | 원격 GitHub 저장소에 반영 |
| 별도 웹사이트 | 선택 사항. 초기 포트폴리오에는 필요 없음 |
| 지원용 PDF | README와 구조 설명을 지원 직무에 맞게 압축하는 후속 작업 |

현재 문서 작성은 commit, push, 웹사이트 배포를 포함하지 않습니다. 공개 시에는 로컬 수정 전체를 자동으로 포함하지 않고, 문서·소스·자료의 반영 범위를 정해 진행합니다.

## 지원용 자료의 구성 초안

1. 프로젝트 목적과 도달점
2. 하드웨어 블록과 PCB
3. 펌웨어 계층과 주변장치 연결
4. 기동·영교차 검출·정류 흐름
5. USB 인식 문제와 고듀티 ZC 문제 해결 — 본문 작성, 증빙 추가 예정
6. 현재 한계와 배운 점 — 작성자 회고 반영 완료

분량을 채우기보다 직접 설명할 수 있는 설계와 관측 결과를 우선합니다. 상용 ESC 비교는 향후 확장 항목으로만 기록합니다.
